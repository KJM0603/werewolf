## 실제 브라우저 검증

`node tests/browser/serve-media.mjs`로 별도 로컬 서버를 실행하고 내장 Chromium 브라우저에서 검증 시작을 눌렀습니다.

- A가 먼저 연결하고 B·C가 나중에 마이크를 켜도 6방향 음성 패킷 수신.
- 같은 연결에 카메라 추가 후 6방향 영상 프레임 디코딩.
- 3명 동시 마이크 시작 및 C → B → A 역순 시작 모두 6방향 수신.
- 최종 화면 `ALL PASS` 확인.

별도 게임 서버에서 `BASE_PATH=/game-werewolf261020`, `PORT=4190`을 지정했습니다. 마지막 `/` 없는 주소의 자동 이동, 화면 로딩, 방 생성, 채팅 전송, 새로고침 후 같은 방 코드와 채팅 기록 복원을 브라우저에서 확인했습니다.

첨부 패치와 두 PDF의 SHA-256을 원본과 비교하여 3개 모두 동일함을 확인했습니다.

## 아직 확인하지 않은 범위

- Cloudflare 실제 계정/키 발급 및 실 API 호출: 제공자가 반환하는 응답은 모의 응답으로 검사했습니다.
- 실제 coturn 릴레이 서버의 미디어 전송: 임시 인증 생성과 앱 전달까지 검사했습니다.
- 서로 다른 이동통신망, 실제 iPhone Safari·카카오톡 내부 브라우저, 운영 서버 배포.

브라우저 전송 검증은 합성 음성·영상을 사용하며 실제 마이크·카메라에 접근하지 않았습니다. 운영 환경에서의 TURN 검증은 [배포 안내](DEPLOYMENT.md)의 `relay` 강제 절차를 따라 주세요.
