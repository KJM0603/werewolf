## 브라우저에서 기능 재현

프로젝트 루트에서 아래 중 필요한 서버 하나를 실행하고 주소를 여세요. 각 서버는 실행 창에서 `Ctrl+C`로 종료합니다.

```powershell
# 도플갱어 복사 능력: http://localhost:4189/
node tests/browser/serve-doppelganger.mjs

# 참가자 3명의 합성 음성·영상 연결: http://localhost:4188/
node tests/browser/serve-media.mjs

# 인물 분리와 배경 가림: http://localhost:4186/
node tests/browser/serve-camera.mjs .local/archive/camera-vendor/portrait.jpg
```

마지막 명령의 사진은 이전 실험 자료로 함께 보관한 파일입니다. 다른 사진 경로를 인자로 주셔도 됩니다. 합성 미디어 검증은 실제 사용자 장치 권한과 서로 다른 네트워크의 연결까지 보장하지 않습니다.

## 보관 자료의 해석

`docs/evidence/2026-10-20/`의 보고서·패치·테스트 결과는 당시의 기록입니다. 일부는 후속 수정 전 상태와 이전 절대 경로를 포함하므로 현재 실행 결과로 사용하지 않습니다. `.local/archive/`의 과거 PID도 실행 중인 프로세스를 뜻하지 않습니다. 현재 테스트 진입점은 `tests/`입니다.

2026-10-21 폴더 정리 과정에서 원래 채팅의 `outputs/` 자료는 이 프로젝트로 복사했습니다. 기존 공유 링크를 유지하기 위해 채팅의 원본 출력 파일도 보존했습니다. 이후 소스 수정과 실행은 이 개발 폴더에서 진행합니다.

## 밤 원탁 화면 검증

프로젝트 루트에서 `node tests/browser/serve-night-table.mjs`를 실행하고 <http://127.0.0.1:4190/>에 접속합니다. 역할·인원·도플갱어 복사 역할을 선택한 뒤 **원탁 테스트 시작**을 누르면 카드 조작을 확인할 수 있습니다. **다음 요청 오류**로 재시도, **시간 종료**로 미제출 행동 종료를 검증합니다. 이 서버는 로컬 전용이며 한 검증 방을 공유하므로 여러 탭을 동시에 사용하지 마세요.

검증 서버만 타이머가 120초입니다. 실제 서비스는 기존 역할별 제한 시간을 사용합니다. 실행 중인 서비스에 서버 변경을 적용하려면 진행 중인 게임을 마친 뒤 재시작하세요. 화면 자료는 `.local/night-table/`에 저장합니다.

늑대인간·프리메이슨은 **동료** 선택으로 혼자/둘이 깨어난 카드를 검증할 수 있습니다. 불면증 환자는 **불면증 확인 카드**에서 그대로 또는 교환 결과를 선택합니다. 교환 검증은 실제 말썽쟁이 처리기로 카드를 바꾼 뒤 불면증 차례에 확인합니다. 도플갱어의 복사 역할에도 늑대인간·프리메이슨·불면증 환자를 선택할 수 있습니다. 다른 검증 서버가 4190을 사용 중이면 `$env:NIGHT_TABLE_PORT='4193'`를 설정한 뒤 실행합니다.
