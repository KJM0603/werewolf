## 밤 원탁 화면 검증

프로젝트 루트에서 `node tests/browser/serve-night-table.mjs`를 실행하고 <http://127.0.0.1:4190/>에 접속합니다. 역할·인원·도플갱어 복사 역할을 선택한 뒤 **원탁 테스트 시작**을 누르면 카드 조작을 확인할 수 있습니다. **다음 요청 오류**로 재시도, **시간 종료**로 미제출 행동 종료를 검증합니다. 이 서버는 로컬 전용이며 한 검증 방을 공유하므로 여러 탭을 동시에 사용하지 마세요.

검증 서버만 타이머가 120초입니다. 실제 서비스는 도플갱어 16초, 늑대인간·예언자·강도·말썽쟁이 각 10초, 주정뱅이 8초, 나머지 밤 역할 각 5초입니다. 늑대인간은 혼자·동료 동반·중앙에만 배치된 경우 모두 같은 10초를 유지하며, 카드 확인을 마쳐도 공개된 종료 시각을 앞당기거나 연장하지 않습니다. 원탁 중앙 카드 3장 아래의 큰 타이머를 확인하며, 불면증 환자는 확대 카드 위에 표시합니다. 실행 중인 서비스에 서버 변경을 적용하려면 진행 중인 게임을 마친 뒤 재시작하세요. 기존 원탁 화면 자료는 `.local/night-table/`, 2026-10-23 타이머 변경 화면은 `.local/night-timer/`에 저장합니다.

밤 시계는 역할명 옆에 `10`, `09`, `08`처럼 남은 초만 표시합니다. 본인 차례 시작 시 전체 화면의 **내 차례** 안내가 약 0.7초 뒤 사라지고, 원탁과 선택 가능한 카드가 은은하게 빛납니다. 선택한 카드는 금색 테두리·체크 또는 1·2 순서로 구분합니다. 안내는 같은 차례의 선택·오류 재시도·도플갱어 즉시 복사 행동·일시정지 후 재개에서 반복하지 않습니다. 동작 줄이기 설정에서는 빛의 반복 애니메이션을 생략합니다.

실제 역할별 시간으로 검증하려면 서버 실행 전에 `$env:NIGHT_TABLE_REALTIME='1'`을 설정합니다. 이때 검증 화면에도 **실제 역할별 시간**으로 표시되며, 기존 120초 검증으로 돌아가려면 해당 환경 변수를 지우고 검증 서버를 재시작합니다. 2026-10-23 차례 안내 화면 자료는 `.local/night-cues/`에 보관합니다.

주정뱅이는 역할을 `drunk`로 선택하고 **원탁 테스트 시작 → 중앙 카드 한 장 → 역할 바꾸기** 순서로 확인합니다. 뒷면 카드 두 장이 내 자리와 선택한 중앙 자리 사이를 반대 방향으로 1초간 이동한 뒤 사라져야 하며, 카드 앞면은 공개되지 않습니다. 카드 발광은 선택 가능한 `button.table-card`에만 적용하여 교환용 `.flying-card`의 `table-swap` 애니메이션을 덮지 않도록 했습니다. 동작 줄이기 설정에서는 기존과 같이 이동 모션을 생략합니다.

## 대기방 강퇴 검증

방장에게만 다른 참가자 옆의 **강퇴** 버튼을 표시합니다. 사람·접속이 끊긴 사람·AI를 내보낼 수 있으며, 방장 자신과 게임 시작 이후의 강퇴는 서버에서 거부합니다. 강퇴 시 역할 구성을 남은 인원 + 3장의 권장 구성으로 변경합니다. 강퇴된 사람은 메인 화면으로 이동하고 저장된 세션·미디어·재접속 대기를 정리합니다. 기존 토큰을 이용한 자동 재접속은 불가능하며, 방 코드로 직접 새로 참가하는 동작은 유지합니다.

로컬 서버 한 개에 방장과 참가자를 각각 접속하여 확인합니다. 한 브라우저에서 확인하려면 `http://127.0.0.1:포트/`와 `http://localhost:포트/`를 나누어 저장된 세션이 겹치지 않게 합니다. 참가자 화면에는 강퇴 버튼이 없고 방장 버튼 클릭 시 참가자가 메인으로 이동해야 합니다. 참가자 화면을 새로고침해도 자동 재입장하지 않는지 확인합니다. 강퇴 요청 중에는 중복 제출을 막고, 오류·전송 실패·8초 무응답 후 다시 시도할 수 있습니다. 320px에서는 상태와 버튼을 세로 배치하고 터치 높이 44px을 유지합니다. 화면 자료는 `.local/lobby-kick/`에 보관합니다.

서비스에는 `server.mjs`, `public/app.js`, `public/styles.css`를 함께 반영한 뒤 진행 중인 게임이 끝나면 서버를 재시작해야 합니다.

- **다음 요청 오류**를 누른 뒤 자기 카드를 클릭하면 재시도를 확인할 수 있습니다. 클릭 전 **시간 종료**를 누르면 직업 확인 없이 다음 단계로 이동합니다.
- 복사 역할에 `minion`, `insomniac`도 지원합니다. 불면증을 복사한 뒤에는 **시간 종료**로 불면증 차례까지 진행합니다.
- 불면증을 복사한 도플갱어는 일반 **불면증 환자** 차례에는 기다리고, 그다음 **도플갱어 · 불면증 환자** 차례에서만 자기 카드를 확인합니다. 인원을 5명 이상으로 설정하고 **불면증 확인 카드**를 늑대인간/예언자로 선택하면 실제 말썽쟁이가 도플갱어의 카드를 바꾼 뒤 마지막에 확인하는 흐름을 재현합니다.
- 도플갱어가 하수인을 복사할 때 **동료 있음**을 선택하면 늑대 한 명을 확인합니다. 처음 복사할 때 본 하수인 카드와, 하수인 능력으로 확인하는 늑대 위치가 구분되어야 합니다.
- 모바일은 `/mobile?width=320`, `/mobile?width=390`에서 확인합니다. 검증 서버만 120초이며 실제 불면증 차례는 기존 5초를 유지합니다. 시스템의 동작 줄이기 설정에서는 확대·뒤집기 애니메이션과 부드러운 자동 스크롤을 생략합니다.

서버가 클릭 후 확인 요청을 처리하므로, 화면 파일 갱신과 함께 `server.mjs`를 반영하고 게임이 끝난 뒤 서버를 재시작해야 합니다.

## 모바일 채팅 배치 검증 (2026-10-22)

`node tests/browser/serve-mobile-chat.mjs` 실행 후 <http://127.0.0.1:4196/>에서 단계·너비·키보드·화면 밀림을 선택하고 **화면 적용**을 누릅니다. **전체 배치 검사**는 대기실·토론·투표, 너비 320/360/390px, 보이는 높이 220/260/320px, 화면 밀림 0/64px의 54개 조합을 검사합니다. 입력칸이 보이는 화면 하단에서 24px 이내에 있고 메시지 두 개 이상이 온전히 보이며, 토론 상단 버튼이 한 줄인지 확인합니다.

실제 소프트 키보드 대신 `visualViewport` 높이와 화면 밀림을 재현하는 로컬 검증입니다. 채팅 전송도 로컬 화면에서만 재현하며 서비스 서버로 전송하지 않습니다. 실제 Android/iOS 키보드 및 외부 배포 검증을 대신하지 않습니다. 기본 포트가 사용 중이면 `MOBILE_CHAT_PORT` 환경 변수로 다른 포트를 지정합니다.

**투표 화면 고정 검사**는 선택한 너비의 10명 투표 화면에서 대상을 선택하고 스크롤한 뒤, 다른 참가자 8명의 제출 인원 갱신을 연속 재현합니다. `sameNodes: true`, `maxShift: 0`, `selected: true`, `pass: true`이면 기존 버튼·채팅 요소와 화면 위치·선택이 유지되고 제출도 실행된 것입니다. 이 검사는 실제 서버 투표를 발생시키지 않습니다.

## 역할 공개 시 초보자 안내

역할 공개 단계의 개인 카드에는 `public/app.js`의 `ROLE_GUIDES`에 정의한 전체 12개 역할의 짧은 안내가 표시됩니다. 카드 또는 **역할 가리기** 버튼을 누르면 역할 이름과 안내가 함께 숨겨지며, 다시 확인하면 함께 표시됩니다. 안내의 읽기 크기·간격은 `public/styles.css`의 `.role-guide`에서 관리합니다. 실제 비공개 카드 결과는 기존 서버 응답으로만 공개됩니다.
