- 토론 상단은 시간·채팅/영상·종료 동의·더보기 한 줄로 정리했습니다. 미디어 재연결·게임 중지·방 정보는 더보기에서 사용할 수 있습니다. 모바일 채팅 제목 줄을 없애 기록 공간을 확보했습니다.
- 전송 버튼 터치 시 입력 포커스를 유지하고, 전송 후 자동 스크롤 이동을 방지합니다. 전송 실패 시 작성 내용은 유지됩니다. 기존 16px 채팅 글씨와 입력 크기를 유지합니다.
- `npm test`: 216개 통과, 실패 0개. 로컬 브라우저의 키보드·화면 밀림 재현 54개 조합에서 입력칸 위치·최근 메시지 2개·상단 한 줄 검사를 모두 통과했습니다. 검증 도구는 `tests/browser/serve-mobile-chat.mjs`입니다.
- 실제 휴대폰 키보드와 외부 Synology 배포 반영은 확인하지 않았습니다. 화면 수정이므로 배포 시 `public/app.js`, `public/styles.css`를 반영하고 브라우저를 새로고침해야 합니다.
