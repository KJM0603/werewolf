- 늑대인간 밤 행동 시간을 5초에서 10초로 늘렸습니다. 혼자 깨어나 중앙을 확인하는 경우, 여러 늑대와 복사한 도플갱어가 함께 깨어나는 경우, 늑대가 중앙에만 있는 경우 모두 동일한 10초를 적용합니다. 확인을 마쳐도 공개 종료 시각은 유지합니다.
- 웹 설명서의 늑대인간 시간을 10초로 정정하고 개발 안내도 갱신했습니다.
- `npm test`: 230개 통과, 실패 0개. 기존 실제 규칙 처리기 기반 테스트에서 혼자·복사 동료 포함 여러 늑대·중앙 배치의 10초, 중앙 확인 후 종료 시각 유지, 시간 종료 및 비공개 정보 범위를 검증했습니다. 추가 코드 실행으로 12개 역할 모두 안내 표시·가리기와 웹 설명서의 10초 표기도 확인했습니다. `git diff --check` 통과.
- 외부 Synology 배포는 수행하지 않았습니다. 적용하려면 `server.mjs`, `public/app.js`, `public/guide/index.html`을 반영한 뒤 진행 중인 게임이 끝나면 서버를 재시작하고 브라우저를 새로고침해야 합니다. 역할 안내 스타일이 없는 이전 배포본에는 `public/styles.css`도 함께 반영해야 합니다.
