# 한밤의 늑대인간

계정 없이 방 코드로 플레이하는 모바일 우선 웹 MVP입니다. Node.js 내장 HTTP 서버와 WebSocket 시그널링을 사용하므로 별도 패키지 설치 없이 실행할 수 있습니다.

## 실행

```powershell
npm start
```

브라우저에서 `http://localhost:4173`을 여세요. 다른 기기에서 접속하려면 같은 네트워크의 서버 PC 주소와 포트 4173을 사용해야 합니다. 마이크와 WebRTC는 배포 시 HTTPS 환경에서 사용하세요.

## 플레이

1. 방을 만들고 초대 코드를 공유합니다.
2. 3명 이상 모이면 방장이 준비된 참가자와 역할 카드 구성을 확인하고 게임을 시작합니다.
3. 카드 N+3장을 섞어 각 참가자에게 한 장씩 나눕니다. 세 장은 중앙 카드로 남습니다.
4. 밤 행동, 토론, 비밀 투표, 결과 공개 순으로 진행합니다.

방장은 인원에 맞는 권장 역할 구성을 쓰거나 역할 카드 수를 직접 조정할 수 있습니다. 도플갱어, 무두장이, 하수인, 프리메이슨(두 장 한 쌍), 사냥꾼도 선택할 수 있습니다.

## 현재 범위와 제한

- 방 상태는 서버 메모리에 저장됩니다. 서버 프로세스가 재시작되면 진행 중인 방은 종료됩니다.
- 음성은 브라우저 간 WebRTC 메쉬 연결과 공개 STUN 서버를 사용합니다. 방화벽이나 대칭 NAT 환경에서는 TURN 서버 설정이 없어 음성 연결이 되지 않을 수 있습니다.
- 실제 기기 화면 전원은 브라우저에서 끌 수 없으므로, 방장 일시정지는 검은 화면 오버레이와 음소거로 구현합니다.
- 권장 조합의 규칙 흐름을 구현한 초기 MVP입니다. 상용 배포 전에는 전체 역할 규칙, 기기별 음성 연결, TURN 환경을 실제 플레이로 검증해야 합니다.

기능 및 상태 흐름은 [DESIGN.md](./DESIGN.md)에 정리되어 있습니다.
