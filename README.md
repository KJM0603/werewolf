# 한밤의 늑대인간

계정 없이 방 코드로 플레이하는 모바일 우선 웹 MVP입니다. Node.js 내장 HTTP 서버와 WebSocket 시그널링을 사용하므로 별도 패키지 설치 없이 실행할 수 있습니다.

## 실행

```powershell
npm start
```

브라우저에서 `http://localhost:4173`을 여세요. 다른 기기에서 접속하려면 같은 네트워크의 서버 PC 주소와 포트 4173을 사용해야 합니다. 마이크와 WebRTC는 배포 시 HTTPS 환경에서 사용하세요.

## 플레이

1. 방을 만들고 초대 코드를 공유합니다.
2. 3명 이상 모이면 방장이 준비된 참가자와 역할 카드 구성을 확인하고 게임을 시작합니다.
3. 카드 N+3장을 섞어 각 참가자에게 한 장씩 나눕니다. 세 장은 중앙 카드로 남습니다.
4. 밤 행동, 토론, 비밀 투표, 결과 공개 순으로 진행합니다.

투표로는 **최다 득표자만** 사망합니다. 최다 득표가 동점이면 그 동점자들만 사망하며, 전원이 1표 이하이면 아무도 사망하지 않습니다. 예를 들어 3표·2표이면 3표를 받은 사람만, 3표·3표·2표이면 3표를 받은 두 사람만 사망합니다. 사망한 사냥꾼이 지목한 사람은 추가로 사망할 수 있습니다. 결과 화면은 생존 여부와 사망 원인을 승패와 별도로 표시합니다.

방장은 인원에 맞는 권장 역할 구성을 쓰거나 역할 카드 수를 직접 조정할 수 있습니다. 도플갱어, 무두장이, 하수인, 프리메이슨(두 장 한 쌍), 사냥꾼도 선택할 수 있습니다.

### 코드와 진행 시간 안내

- 초대 코드는 **6자리**입니다.
- 한 판은 연장 없이 **약 12분**입니다. 기본 토론 10분에 역할 확인·밤 행동·투표·결과 공개 시간이 더해지며, 토론 연장이나 과반 동의 종료에 따라 달라집니다.
- 현재 밤 행동 시간은 도플갱어 **13초**, 예언자·강도·말썽쟁이 **각 7초**, 그 밖의 밤 역할은 **각 5초**입니다. 도플갱어의 즉시 복사 능력은 도플갱어의 13초 구간 안에서 사용합니다.
- 역할이 중앙에만 있어도 같은 시간 동안 진행하여 타이머로 역할 배치를 추측할 수 없게 합니다.
- 방장이 중지 버튼을 누르면 **“방장이 게임을 일시정지했습니다.”**라고 안내합니다. 연결 끊김 자체로 자동 정지하지 않습니다.

### 도플갱어의 복사 행동

- 예언자·강도·말썽쟁이·주정뱅이를 복사하면, 복사 직후 화면 위에 나타나는 행동 선택으로 능력을 수행합니다. 복사와 후속 행동 모두 기존 13초 안에 완료해야 합니다.
- 늑대인간·프리메이슨·불면증 환자는 해당 역할 차례에 참여하고, 하수인은 복사 직후 늑대인간 정보를 받습니다. 주민·무두장이·사냥꾼은 추가 밤 행동이 없습니다.
- 서버 응답 전에는 실행 버튼이 처리 중으로 표시됩니다. 전송 실패나 입력 오류가 나면 선택 화면을 유지하여 다시 제출할 수 있고, 시간이 끝나면 미제출 행동이 적용되지 않았음을 안내합니다.
- 화면에서 재현하려면 `node tests/browser/serve-doppelganger.mjs` 실행 후 `http://localhost:4189`에서 역할을 선택하고 테스트를 시작하세요. 실제 서버 규칙과 화면 코드를 사용하며, 매번 도플갱어를 배정합니다. 실제 게임 서버와는 분리된 테스트입니다.

### 봇과 테스트

- 대기실에서 추가할 AI 인원을 선택해 여러 번 추가할 수 있습니다. 사람과 AI를 합쳐 최대 10명입니다.
- 봇이 있는 방에서는 방장에게 건너뛰기 버튼이 표시됩니다. 밤 전체 건너뛰기는 남은 봇 능력을 처리한 뒤 토론으로 이동하며, 아직 제출하지 않은 사람의 밤 행동은 생략합니다.
- 투표 건너뛰기는 미완료 봇 투표를 먼저 처리하고 결과를 공개합니다. 이미 제출한 사람의 표는 유지하며, 미제출한 사람의 표만 무효표로 처리합니다.
- 최종 늑대가 없더라도 참가자가 처치되면 마을 팀은 패배할 수 있습니다. 승리자가 없을 때는 안내와 결과 화면 모두 이를 표시합니다.

### 과반 동의로 토론 종료

- 토론 화면의 **토론 종료 동의** 버튼은 모든 사람 참가자가 사용할 수 있습니다. 과반에 도달하기 전에는 동의를 취소할 수 있습니다.
- 사람 참가자의 절반을 초과하면 즉시 비밀 투표로 넘어갑니다. 3명은 2명, 4명은 3명, 5명은 3명의 동의가 필요합니다.
- 봇은 기준 인원과 동의 집계에서 제외합니다. 사람 1명과 봇으로 테스트할 때는 그 사람의 동의로 종료됩니다.
- 연결이 끊겨도 기준 인원과 기존 동의는 유지하며, 재접속하면 현황을 복원합니다. 일시정지 중에는 동의를 변경할 수 없습니다.
- 봇이 있는 방의 기존 방장 토론 건너뛰기 요청도 동의 1표로 처리하므로 여러 사람의 과반 기준을 우회하지 않습니다.

규칙 및 화면 회귀 테스트는 `npm test`로 실행합니다.
봇 없이 실제 WebSocket 클라이언트 3개로 과반 동의를 검증하려면 `node tests/live-multiplayer.mjs`를 실행하세요. 별도 테스트 서버(기본 4187 포트)를 실행하고 검증 후 종료합니다.

### 카메라 배경 가림

- 카메라를 켜면 인물 영역만 남기고 배경을 어두운 단색으로 가립니다. 내 화면과 상대방 화면에 같은 처리 영상이 표시됩니다.
- 원본 카메라 트랙은 상대방에게 연결하지 않습니다. 인물 분리는 브라우저 안의 별도 작업 스레드에서 처리하며, 모델과 실행 파일도 게임 서버에서 제공합니다.
- 첫 처리 영상이 준비된 뒤에만 카메라를 켭니다. 준비 실패·처리 중단·카메라 해제·토론 종료 시에는 카메라를 끄며 원본 영상으로 전환하지 않습니다.
- 최신 Chrome/Edge의 HTTPS 또는 localhost 환경을 권장합니다. Worker, OffscreenCanvas, canvas.captureStream을 지원하지 않는 환경에서는 카메라를 켜지 않습니다.
- 자동 인물 분리는 조명과 움직임에 따라 경계가 부정확할 수 있습니다. 민감한 물건은 몸 가까이에 두지 않는 편이 안전합니다.
- 공개 인물 사진을 가상 카메라로 쓰는 실제 모델/WebRTC 검증 화면은 `tests/browser/camera.html`입니다. `node tests/browser/serve-camera.mjs <예제사진.jpg>`를 실행한 후 `http://localhost:4186`에서 검증할 수 있습니다. 검증에는 [MediaPipe 공개 예제 사진](https://storage.googleapis.com/mediapipe-assets/portrait.jpg)을 사용했습니다.

### 다중 참가자 음성·영상

- 토론에 들어가면 참가자마다 양방향 연결을 준비합니다. 마이크·카메라를 늦게 켜도 이미 맺은 연결로 전송할 수 있습니다.
- 마이크는 직접 켠 뒤에만 접근하며, 카메라는 배경 가림 영상만 전송합니다. 권한 차단·장치 없음·장치 사용 불가와 연결 협상 오류를 구분해 안내합니다.
- 브라우저가 상대 소리의 자동 재생을 차단하면 **상대 소리 재생** 버튼을 누르세요.
- 실제 장치 없이 전송 경로를 검증하려면 `node tests/browser/serve-media.mjs` 실행 후 `http://localhost:4188`에서 **검증 시작**을 누르세요. 실제 앱의 연결 코드와 브라우저 WebRTC를 사용해 참가자 3명의 순차·동시·역순 마이크 시작, 6방향 음성 수신, 카메라 추가 후 6방향 영상 디코딩을 확인합니다.
- 이 검증은 합성 미디어를 사용합니다. 각 사용자의 실제 장치 권한이나 서로 다른 네트워크의 방화벽 통과 여부까지 보장하지는 않습니다.

## 현재 범위와 제한

- 방 상태는 서버 메모리에 저장됩니다. 서버 프로세스가 재시작되면 진행 중인 방은 종료됩니다.
- 음성은 브라우저 간 WebRTC 메쉬 연결과 공개 STUN 서버를 사용합니다. 방화벽이나 대칭 NAT 환경에서는 TURN 서버 설정이 없어 음성 연결이 되지 않을 수 있습니다.
- 실제 기기 화면 전원은 브라우저에서 끌 수 없으므로, 방장 일시정지는 검은 화면 오버레이와 음소거로 구현합니다.
- 권장 조합의 규칙 흐름을 구현한 초기 MVP입니다. 상용 배포 전에는 전체 역할 규칙, 기기별 음성 연결, TURN 환경을 실제 플레이로 검증해야 합니다.

기능 및 상태 흐름은 [DESIGN.md](./DESIGN.md)에 정리되어 있습니다.
